# IAM-LABS

Microsoft Entra ID / Identity and Access Administrator (SC-300) learning and hands-on portfolio.

## Purpose

This repository documents a progressive Microsoft Entra IAM lab environment designed around the Microsoft Learn SC-300 training paths.

The project combines:

- SC-300 exam preparation
- Microsoft Entra administration
- Hands-on IAM labs
- PowerShell / Microsoft Graph automation
- Troubleshooting practice
- Interview preparation
- Employer-facing documentation

## Microsoft Learn Roadmap

| Week | Learning Path | Modules |
|---|---|---:|
| Week 1 | Implement an identity management solution using Microsoft Entra ID | 4 |
| Week 2 | Implement an authentication and access management solution | 6 |
| Week 3 | Implement access management for apps | 4 |
| Week 4 | Plan and implement an identity governance strategy | 4 |

## Weekly Workflow

1. Microsoft Learn evaluation

5. Evidence/screenshots

## Administrator Troubleshooting Model

Use the same structured approach across the project:

**Identity → Scope → Policy/Role → Configuration → Logs → Resource/Application → Result**

For processes with additional infrastructure, expand the sequence rather than guessing.

## Portfolio Goal

The finished repository should demonstrate that the administrator can:

- understand Microsoft Entra architecture
- configure identity and access controls
- apply least privilege
- troubleshoot access failures
- automate repeatable administration
- document changes clearly
- explain IAM decisions in an interview

## Microsoft Learn Alignment

This repository follows Microsoft's SC-300 Identity and Access Administrator training structure and is updated as Microsoft Learn changes.
