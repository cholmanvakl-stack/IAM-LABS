# D6 Lab — Global Secure Access

## Goal
Understand identity-aware network access using Microsoft Entra Global Secure Access.

## Tasks
1. Review the Global Secure Access dashboard.
2. Compare Internet Access and Private Access.
3. Review traffic forwarding profiles.
4. Review the Global Secure Access client.
5. Review remote networks.
6. Review Conditional Access integration.
7. Review logging and monitoring.
8. Document a Zero Trust access flow.

## Validation
Explain acquisition → policy → routing → destination → logging.

## Evidence
Add dashboard, profiles, CA, remote network, and logging screenshots where available.

## Troubleshooting
**User → Client/Network → Traffic Profile → Conditional Access → Destination → Logs → Result**
