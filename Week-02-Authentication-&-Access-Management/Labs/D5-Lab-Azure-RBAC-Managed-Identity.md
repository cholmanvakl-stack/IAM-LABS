# D5 Lab — Azure RBAC & Managed Identities

## Goal
Practice least-privilege authorization for Azure resources.

## Tasks
1. Review built-in Azure RBAC roles.
2. Assign a role at an intentionally narrow scope.
3. Review role permissions.
4. Compare built-in and custom roles.
5. Review system-assigned vs user-assigned managed identities.
6. Assign a managed identity to a supported Azure resource when available.
7. Review access to Azure Key Vault using RBAC.
8. Document the difference between identity authentication and Azure authorization.

## Validation
Explain principal, role definition, scope, assignment, and managed identity.

## Evidence
Add role assignment, role definition, managed identity, and Key Vault screenshots.

## Troubleshooting
**Principal → Role Definition → Scope → Assignment → Token/Identity → Resource → Result**
