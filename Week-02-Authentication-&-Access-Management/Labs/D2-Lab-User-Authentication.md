# D2 Lab — User Authentication

## Goal
Understand and validate Microsoft Entra authentication methods and password security controls.

## Tasks
1. Review FIDO2/passwordless authentication.
2. Review Authenticator and OATH methods.
3. Review Windows Hello for Business.
4. Review SSPR.
5. Review password protection and smart lockout.
6. Review certificate-based authentication.
7. Review Kerberos and Azure VM authentication concepts.
8. Review tenant restrictions.
9. Document which control solves which authentication problem.

## Validation
Build a method-to-scenario mapping and identify the authentication dependency for each method.

## Evidence
Add configuration and sign-in screenshots where available.

## Troubleshooting
**User → Method → Registration → Policy → Credential/Infrastructure → Tenant/Resource → Sign-In Result → Verify**
