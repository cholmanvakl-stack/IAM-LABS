# D3 Lab — Conditional Access

## Goal
Build, test, and troubleshoot Conditional Access safely.

## Tasks
1. Review Security Defaults.
2. Identify CA policy design requirements.
3. Create a test CA policy using report-only mode when appropriate.
4. Configure users/groups, target applications, and conditions.
5. Configure grant controls.
6. Configure session controls.
7. Review authentication session behavior and CAE.
8. Test the policy.
9. Inspect sign-in logs and policy evaluation.

## Safety
Exclude emergency access accounts from test enforcement policies and verify scope before enabling.

## Validation
Explain conditions, grant controls, session controls, report-only testing, and sign-in evidence.

## Evidence
Add policy, assignment, report-only, and sign-in-log screenshots.

## Troubleshooting
**User → Application → Conditions → Policy → Grant Controls → Session Controls → Sign-In Logs → Verify**
