# D1 Lab — Microsoft Entra MFA

## Goal
Configure and validate strong authentication concepts without locking out the lab administrator.

## Tasks
1. Review available authentication methods.
2. Review Microsoft Authenticator and passwordless methods.
3. Review FIDO2/security key concepts.
4. Review OATH token concepts.
5. Review authentication strengths.
6. Review MFA registration state.
7. Test MFA with a dedicated lab user.
8. Document the relationship between MFA and Conditional Access.

## Safety
Always maintain a break-glass/emergency access path before testing enforcement.

## Validation
Demonstrate factor selection, registration, policy enforcement, and successful sign-in.

## Evidence
Add screenshots of methods, registration, authentication strength, and sign-in evidence.

## Troubleshooting
**User → Registration → Method → Policy → Authentication Strength → Sign-In Result → Verify**
