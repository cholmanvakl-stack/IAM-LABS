# Learning Path 01 — Implement an Identity Management Solution

## Main concept
**Establish and manage identities in Microsoft Entra ID: tenant configuration → users and groups → external collaboration → hybrid synchronization.**

[Official Microsoft Learn path](https://learn.microsoft.com/en-us/training/paths/implement-identity-management-solution/)

## How these modules connect

- `Initial Microsoft Entra configuration` establishes the tenant, administrative boundaries, roles, and identity settings that all other identity operations depend on.
- `Identity management` creates and maintains users, groups, licenses, and devices so people and workloads can receive the right access.
- `External identities` extends controlled collaboration to guests and partner organizations while maintaining tenant security boundaries.
- `Hybrid identity` connects on-premises Active Directory with Microsoft Entra ID through synchronization and supported authentication methods.

Together: **Tenant configuration → Identity lifecycle → External collaboration → Hybrid integration.**

Each module follows: Main concept → Core knowledge → How concepts connect → SC-300 exam decisions → Troubleshooting → Check understanding.
