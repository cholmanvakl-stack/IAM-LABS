# Learning Path 04 — Plan and Implement an Identity Governance Strategy

## Main concept
**Govern who receives access, how long they keep it, who verifies continued need, how privileged access is controlled, and how access activity is monitored throughout the identity lifecycle.**

**Access request → Approval and assignment → Periodic review → Privileged activation → Expiration or removal → Monitoring and audit**

[Official Microsoft Learn path](https://learn.microsoft.com/en-us/training/paths/plan-implement-identity-governance-strategy/)

## How these modules connect
- `Entitlement management` determines how access is requested, approved, provisioned, and expires.
- `Access reviews` confirm whether access should continue.
- `Privileged Identity Management (PIM)` reduces standing administrative privileges through time-bound activation.
- `Monitoring and auditing` show sign-ins, changes, governance decisions, and risks.

Each module follows: Main concept → Core knowledge → How concepts connect → SC-300 exam decisions → Troubleshooting → Check understanding.
