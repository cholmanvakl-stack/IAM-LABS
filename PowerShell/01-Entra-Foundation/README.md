# PowerShell — Week 1 Entra Foundation

## Purpose

These scripts were created as part of IAM Labs Week 1 to begin learning how Microsoft Entra administration can be performed through PowerShell and Microsoft Graph.

The goal is to develop scripting skills alongside hands-on Entra administration.

## Scripts

### Connect-MgGraph.ps1

Connects PowerShell to Microsoft Graph and displays the current Graph session.

**Skills demonstrated:**
- Microsoft Graph authentication
- Permission scopes
- Checking the current Graph context

### Get-TenantInfo.ps1

Retrieves basic Microsoft Entra tenant information.

**Skills demonstrated:**
- Retrieving tenant information
- Variables
- Selecting specific properties

### Get-EntraUsers.ps1

Retrieves Entra users and displays selected identity properties.

**Skills demonstrated:**
- Microsoft Graph user queries
- Retrieving all users
- Filtering displayed properties

### Get-EntraGroups.ps1

Retrieves Entra groups and displays selected group properties.

**Skills demonstrated:**
- Microsoft Graph group queries
- Group property inspection
- Security-enabled group identification

## Week 1 Learning Progression

The scripting progression for Week 1 is:

**Connect → Inspect → Retrieve → Display**

The scripts complement the manual Entra administration performed during the Week 1 labs.
