# IAM LABS — Day 3 PowerShell

## External Identity Administration

**Objective:**  
Use Microsoft Graph PowerShell to inspect and document Microsoft Entra external identities, guest users, dynamic groups, cross-tenant access, and external identity providers.

**Portfolio title:**  
**IAM LABS Week 1 — Day 3 PowerShell: External Identity Administration**

---

## Scripts

### 01 — Get Guest Users

**Script:**  
`01-Get-GuestUsers.ps1`

**Purpose:**  
Retrieve and identify guest users in the Microsoft Entra tenant.

**Skills practiced:**
- Microsoft Graph PowerShell
- Guest user administration
- User filtering
- Microsoft Entra identity management

### 02 — Get Guest User Properties
