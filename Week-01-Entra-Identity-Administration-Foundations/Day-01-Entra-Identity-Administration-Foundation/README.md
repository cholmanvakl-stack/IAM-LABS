# Day 01 — Entra Identity Administration Foundation

## Overview

Day 01 establishes the foundational structure of Microsoft Entra ID.

The lab focused on inspecting an existing Microsoft Entra tenant and documenting its identity administration structure, administrative roles, delegated administration capabilities, domain configuration, and tenant-wide settings.

No unnecessary configuration changes were made. The goal was to establish a documented baseline of the environment before performing configuration-focused labs later in the program.

## Topics Covered

### Microsoft Entra ID

Understanding the tenant as the organization's cloud identity and access management environment.

### Company Branding

Understanding how an organization can customize the Microsoft Entra sign-in experience.

### Microsoft Entra Roles

Understanding how administrative roles control what administrators can do within the tenant.

### Administrative Units

Understanding how Administrative Units provide a scope for delegated administration.

### Role Permissions

Understanding the permissions provided by Entra roles and the principle of least privilege.

### Custom Domains

Understanding how organizational domains are added and verified within Microsoft Entra ID.

### Tenant-Wide Settings

Understanding configuration that affects the broader Microsoft Entra tenant.
