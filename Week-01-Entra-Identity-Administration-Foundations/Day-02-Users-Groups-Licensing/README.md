## Topics Covered

### Users

Understanding user identities, user properties, account status, and the user lifecycle.

### Groups

Understanding group types, group owners, members, and membership management.

### Dynamic Groups

Understanding how membership rules use user or device attributes to automatically determine group membership.

### Licensing

Understanding direct user licensing, available tenant licenses, and group-based licensing concepts.

### Identity Relationships

Understanding how user attributes, group membership, access, and licensing can work together to support scalable identity administration.
