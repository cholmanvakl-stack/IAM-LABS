# D3 Lab — External Identities

## Goal
Administer guest/B2B access while maintaining control over external collaboration.

## Tasks
1. Review external collaboration settings.
2. Review guest invitation controls.
3. Invite a test guest if available.
4. Review the guest's User Type and lifecycle.
5. Create or inspect a dynamic group for guest users.
6. Review cross-tenant default settings.
7. Review inbound and outbound cross-tenant access.
8. Review configured identity providers.

## Validation
- Guest identity exists only as needed.
- Authentication and authorization are treated separately.
- Cross-tenant inbound/outbound controls are understood.
- Dynamic guest membership behaves as expected.

## Troubleshooting
**Guest Identity → Invitation → Authentication → Collaboration Settings → Cross-Tenant Controls → Group / Resource Access → Dynamic Membership → Verify**

Key rule: successful authentication does not prove authorization.
