# D2 Lab — Users, Groups & Licensing

## Goal
Practice identity lifecycle administration and automated group/licensing management.

## Tasks
1. Create or inspect test users.
2. Review user properties and UPNs.
3. Disable and restore a test identity where safe.
4. Review deleted users.
5. Create assigned and dynamic security groups.
6. Build a dynamic rule using an attribute such as Department.
7. Review group owners and members.
8. Review direct and group-based licenses.
9. Verify dynamic membership changes.

## Validation
- User lifecycle states are understood.
- Assigned vs dynamic membership is demonstrated.
- Group-based licensing is understood.
- Attribute changes produce expected membership changes.
