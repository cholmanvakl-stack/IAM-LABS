# D4 Lab — Hybrid Identity

## Goal
Understand and demonstrate the architecture used to synchronize on-premises identities with Microsoft Entra ID.

## Tasks
1. Compare Microsoft Entra Connect Sync and Cloud Sync.
2. Document the source AD scope and synchronization scope.
3. Review PHS, PTA, and federation.
4. Review Seamless SSO.
5. Review synchronization errors and health concepts.
6. Document Connect Health responsibilities.
7. If no hybrid server exists, complete the exercise as an architecture/configuration review rather than inventing production changes.

## Validation
Explain:
- synchronization vs authentication
- PHS vs PTA vs federation
- Connect Sync vs Cloud Sync
- Seamless SSO
- Connect Health
