# Describe the embedded experiences of Microsoft Security Copilot

## Main concept
`Embedded Security Copilot experiences` make AI assistance available inside supported Microsoft security products and their existing investigation workflows.

**Official Microsoft Learn module:** https://learn.microsoft.com/en-us/training/modules/security-copilot-embedded-experiences/

## Core knowledge
- Microsoft Defender XDR incident and artifact investigation
- Microsoft Purview data protection and compliance scenarios
- Microsoft Entra identity-related scenarios
- Microsoft Intune device and policy scenarios
- Microsoft Defender for Cloud cloud security scenarios
- Standalone versus embedded experience

## How concepts connect
Embedded Copilot keeps analysts close to the product and evidence they are already using; standalone Copilot supports broader cross-product exploration.

## SC-200 exam decisions
Match a security task to the appropriate product and embedded experience; do not confuse an AI-generated recommendation with an automatically completed remediation.

## Troubleshooting
Check product availability → user role → license/enablement → supported scenario → source evidence → action status.

## Check understanding
1. Where would you investigate a suspicious Defender XDR incident versus a Purview data protection alert?
2. What security product, data source, or feature would you use first, and why?
3. How would you verify that the output is accurate and that any recommended action is safe?

**Study tip:** Use the pattern `task → context → data source → Copilot response → evidence validation → analyst decision`.
