# Experience Security Copilot through guided simulations

## Main concept
`Guided simulations` demonstrate Security Copilot investigation workflows, including promptbooks, incident analysis, data protection, and agents.

**Official Microsoft Learn module:** https://learn.microsoft.com/en-us/training/modules/security-copilot-interactive-guides/

## Core knowledge
- Owner settings in Security Copilot
- Investigation prompts and custom promptbooks
- Purview data protection, DLP and insider-risk scenarios
- Defender XDR incidents and artifacts
- Exploring and creating Security Copilot agents
- Conditional Access Optimization Agent suggestions
- Documenting and validating findings from simulations

## How concepts connect
Simulations connect foundational prompting and product integrations to the analyst's full workflow: question → evidence → interpretation → decision → validation.

## SC-200 exam decisions
Identify which experience or workflow fits a given security scenario; recognize the role of approvals, permissions and human review.

## Troubleshooting
Check simulated scenario → prerequisites and roles → source product data → prompt or agent output → recommended action → verified outcome.

## Check understanding
1. How would you validate an agent's proposed Conditional Access change before applying it to production?
2. What security product, data source, or feature would you use first, and why?
3. How would you verify that the output is accurate and that any recommended action is safe?

**Study tip:** Use the pattern `task → context → data source → Copilot response → evidence validation → analyst decision`.
