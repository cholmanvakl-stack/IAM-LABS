# Describe Microsoft Security Copilot

## Main concept
`Microsoft Security Copilot` assists security teams with natural-language investigations, explanations, and workflows grounded in accessible security data.

**Official Microsoft Learn module:** https://learn.microsoft.com/en-us/training/modules/security-copilot-getting-started/

## Core knowledge
- Security Copilot purpose and terminology
- How a prompt request is processed
- Elements of an effective prompt: goal, context, source and desired output
- Enabling and configuring Security Copilot
- Role-based access and data availability

## How concepts connect
Security Copilot augments rather than replaces the analyst: it helps interpret evidence and speed up investigation, while the analyst determines accuracy and actions.

## SC-200 exam decisions
Recognize effective prompts, deployment prerequisites, permissions, and the difference between assistance and verified conclusions.

## Troubleshooting
Check service enablement → user permissions → available security data → prompt scope → output evidence.

## Check understanding
1. What context should a prompt include when asking Copilot to summarize a suspicious sign-in incident?
2. What security product, data source, or feature would you use first, and why?
3. How would you verify that the output is accurate and that any recommended action is safe?

**Study tip:** Use the pattern `task → context → data source → Copilot response → evidence validation → analyst decision`.
