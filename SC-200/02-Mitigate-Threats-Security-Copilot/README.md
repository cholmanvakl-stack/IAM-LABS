# SC-200 — Mitigate threats using Microsoft Security Copilot

## Main concept
`Microsoft Security Copilot` supports Blue Team investigations through AI-assisted prompts, connected security data, repeatable workflows and embedded experiences. Analysts remain responsible for validating evidence and making response decisions.

**Official Microsoft Learn learning path:** https://learn.microsoft.com/en-us/training/paths/sc-200-mitigate-threats-using-microsoft-copilot-for-security/

**Certification:** [Microsoft Certified: Security Operations Analyst Associate](https://learn.microsoft.com/en-us/credentials/certifications/security-operations-analyst/)

## The mental model
`Security question → Clear prompt → Available plugins/data → Generated analysis → Source validation → Analyst action`. `Promptbooks` standardize repeatable steps, `agents` can support more complex workflows, and embedded experiences place assistance directly within Microsoft security products. Copilot output is an aid, not a substitute for verifying telemetry.
