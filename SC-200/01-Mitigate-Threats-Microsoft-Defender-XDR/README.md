# SC-200 — Mitigate threats using Microsoft Defender XDR

## Main concept
`Microsoft Defender XDR` brings together signals from identities, endpoints, email, and cloud apps so a Blue Team analyst can detect, investigate, contain, and remediate threats.

**Official Microsoft Learn learning path:** https://learn.microsoft.com/en-us/training/paths/sc-200-mitigate-threats-using-microsoft-365-defender/

**Certification:** [Microsoft Certified: Security Operations Analyst Associate](https://learn.microsoft.com/en-us/credentials/certifications/security-operations-analyst/)

## The mental model
`Security signals → Alerts → Correlated incident → Investigation → Response/remediation → Validation and reporting`. The Defender products provide different perspectives on a threat; the unified portal helps an analyst connect the evidence. Identity concepts from SC-300 are particularly useful for risk-based investigations.
