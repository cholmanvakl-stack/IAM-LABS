# Search for content with Microsoft Purview eDiscovery

## Main concept
`Microsoft Purview eDiscovery` supports authorized searches for organizational content across Microsoft 365, using cases, scoped queries, result validation, and controlled exports.

**Official Microsoft Learn module:** https://learn.microsoft.com/en-us/training/modules/purview-ediscovery-search/

## Core knowledge
- eDiscovery purposes and content-search capabilities
- Roles, permissions and least-privilege access
- Creating and managing eDiscovery cases
- Search locations across Exchange, SharePoint and Teams
- Keywords, conditions and Copilot-assisted query construction
- Search execution, statistics, samples and validation
- Exporting search results and evidence handling

## How concepts connect
Authorized investigators create a case, select custodians or locations, construct a defensible query, evaluate result completeness, and export only appropriately scoped evidence.

## SC-200 exam decisions
Distinguish audit events from content discovery; select correct search locations and roles; validate result statistics and samples before interpreting absence or presence of content.

## Troubleshooting
Check role permissions → case membership → search locations → query syntax and filters → indexing/search results → export permissions and completeness.

## Check understanding
1. When would you use Purview Audit rather than eDiscovery?
2. A search returns zero results for a known document. What scope and query checks should come first?
3. Why validate statistics or samples before exporting results?

**Study tip:** Explain scenarios using `source → scope → evidence → investigation → decision → remediation or case action → validation`. Follow organizational authorization and privacy requirements.
