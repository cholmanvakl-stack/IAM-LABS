# D4 Lab — Application Object & Service Principal

## Goal
Understand how Entra represents an application and its tenant-local identity.

## Tasks
1. Register a single-tenant test application.
2. Review the application object.
3. Review the service principal.
4. Compare single-tenant and multitenant designs.
5. Review app authentication options.
6. Review API permissions and app roles.
7. Document which object owns which configuration.

## Validation
- Application object = global app definition.
- Service principal = tenant-local representation used for access.

## Evidence
Add object/service-principal screenshots and permission evidence.

## Troubleshooting
**Application Object → Service Principal → Authentication → API Permissions → Consent → Token → Resource**
