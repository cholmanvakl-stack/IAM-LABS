# D3 Lab — App Registration & API Permissions

## Goal
Create and govern application identities.

## Tasks
1. Register a test application.
2. Select the correct supported account type.
3. Review the application object.
4. Configure authentication.
5. Add delegated API permissions.
6. Add application permissions only when required.
7. Review admin consent requirements.
8. Review app roles and authorization.
9. Inspect the resulting service principal.

## Validation
Explain delegated vs application permissions and consent.

## Evidence
Add registration, authentication, API permission, consent, and service principal screenshots.

## Troubleshooting
**Registration → Authentication → Permission → Consent → Token → Application → Logs**
