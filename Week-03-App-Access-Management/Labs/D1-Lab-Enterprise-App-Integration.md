# D1 Lab — Enterprise App Integration & Assignment

## Goal
Discover, integrate, assign, and govern enterprise application access.

## Tasks
1. Review enterprise application discovery/Shadow IT concepts.
2. Review Defender for Cloud Apps discovery.
3. Review AD FS application reports.
4. Review application connectors.
5. Select a preintegrated gallery SaaS application.
6. Review SSO configuration.
7. Assign access to a test group.
8. Review app management roles.
9. Review OAuth app policies and consent.

## Validation
Separate SSO, assignment, Conditional Access, and OAuth consent.

## Evidence
Add app discovery, gallery app, SSO, assignment, and consent screenshots.

## Troubleshooting
**Discovery → Integration → Connector → Authentication → Assignment → Consent → Conditional Access → Application → Logs → Result**
