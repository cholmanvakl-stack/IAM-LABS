# D2 Lab — Implement & Monitor Enterprise Apps

## Goal
Operate enterprise applications after integration.

## Tasks
1. Review token customization concepts.
2. Review consent settings.
3. Review Application Proxy architecture.
4. Review custom SaaS SSO configuration.
5. Review application provisioning.
6. Review audit and sign-in evidence.
7. Review application collections.
8. Document an app access troubleshooting case.

## Validation
Explain how SSO, assignment, consent, provisioning, CA, and logs interact.

## Evidence
Add app configuration, provisioning, monitoring, and audit screenshots.

## Troubleshooting
**Application → SSO → Assignment → Consent → Provisioning → Conditional Access → Logs → Result**
