# Day 1 Screenshots

This folder contains screenshots used as evidence for the Day 1 IAM LABS project.

## Naming Convention

Screenshots should use numbered names corresponding to the lab step.

Example:

- `01-tenant-overview.png`
- `02-tenant-properties.png`
- `03-custom-domains.png`
- `04-tenant-settings.png`

Screenshots should demonstrate configuration, actions, or validation results relevant to the lab.
