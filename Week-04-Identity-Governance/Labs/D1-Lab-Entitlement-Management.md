# D1 Lab — Entitlement Management

## Goal
Automate governed access requests and lifecycle management.

## Tasks
1. Review entitlement management.
2. Create or inspect a catalog.
3. Create an access package.
4. Add resources.
5. Configure request policy and approval.
6. Review terms of use.
7. Review connected organizations/external users.
8. Review assignment and expiration lifecycle.

## Validation
Explain catalog → package → policy → request → approval → assignment → lifecycle.

## Evidence
Add catalog, package, policy, approval, and assignment screenshots.

## Troubleshooting
**Catalog → Package → Policy → Request → Approval → Assignment → Lifecycle → Result**
