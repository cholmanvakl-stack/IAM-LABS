# D4 Lab — Monitor & Maintain Microsoft Entra ID

## Goal
Use logs and monitoring to investigate identity events and maintain tenant security.

## Tasks
1. Review sign-in logs.
2. Review Entra audit logs.
3. Correlate sign-in and configuration changes.
4. Review Microsoft Sentinel/SIEM integration concepts.
5. Review workbooks/reporting.
6. Review Identity Secure Score.
7. Document a sample investigation.
8. Identify remediation and verification steps.

## Validation
Demonstrate evidence-driven investigation rather than guessing.

## Evidence
Add sign-in, audit, correlation, reporting, and Secure Score screenshots.

## Troubleshooting
**User → Sign-In Log → Conditional Access → Audit Log → Resource/Application → Correlation → Remediation**
