# D2 Lab — Access Reviews

## Goal
Continuously validate that users retain only the access they need.

## Tasks
1. Review access review planning.
2. Create or inspect a group/app review.
3. Configure reviewers.
4. Configure recurrence where appropriate.
5. Review findings and recommendations.
6. Record reviewer decisions.
7. Review automated remediation behavior.
8. Review the Access Review Agent concept.

## Validation
Explain target → reviewer → schedule → findings → decision → remediation.

## Evidence
Add target, reviewer, findings, decision, and remediation screenshots.
